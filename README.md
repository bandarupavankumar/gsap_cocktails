## 🚀 Tech Stack

### ⚛️ React
- Component-based architecture for scalable UI
- Clean integration with GSAP animation timelines
- State-driven UI logic for carousels and interactive sections

### 🎬 GSAP (GreenSock Animation Platform)
- SplitText animations for dynamic text reveals
- ScrollTrigger for scroll-based animation control
- Parallax scrolling and pinned sections
- Scroll-synced video playback
- Image masking and seamless timeline animations
- Fully custom animated carousel

### 🎨 Tailwind CSS
- Utility-first styling approach
- Responsive and mobile-first design
- Clean and maintainable UI structure
- Animation-friendly layout system

### ⚡ Vite
- Lightning-fast development server
- Instant Hot Module Replacement (HMR)
- Optimized production builds
- Ideal for animation-heavy React applications
